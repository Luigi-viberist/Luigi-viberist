## 🚀 Getting Started (a.k.a. "How to run my project")

```bash
# 1. Clone it
git clone https://github.com/Luigi-viberist/your-awesome-repo.git

# 2. Go inside
cd your-awesome-repo

# 3. Pray
composer install

# 4. Copy env and pretend you know what's in it
cp .env.example .env

# 5. Generate the key (feels very hacker-ish)
php artisan key:generate

# 6. Migrate and hope nothing explodes
php artisan migrate

# 7. Serve it
php artisan serve
```

If it doesn't work:

1. Try `composer dump-autoload`
2. Try `php artisan optimize:clear`
3. Try turning it off and on again
4. Try crying
5. Check if you forgot `.env`. (You forgot `.env`.)
